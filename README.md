# Legal Research Assistant and RAG Pipeline for the NBA's Collective Bargaining Agreement

## Overview:
NBA CBA 2023 RAG system. Ingests the NBA Collective Bargaining Agreement PDF into a Pinecone vector index, then retrieves relevant sections to answer natural language questions.

## Stack:  
### Models: 
- Embedding: multi-qa-mpnet-base-dot-v1 (https://huggingface.co/sentence-transformers/multi-qa-mpnet-base-dot-v1)
- Synthetic Evaluation Query Generation: Claude Haiku 4.5
- LLM Judge: Claude Haiku 4.5

Vector DB:
- Pinecone

Dev Tools:
- Claude Code
- Git/Github


## Data
- 2023 NBA Collective Bargaining Agreement (pdf)

## Pipeline:
1. Chunking
    - **Strategy**: Section-level chunking + recursive overflow splitting

2. Embedding
    - **Model**: multi-qa-mpnet-base-dot-v1
    - **Strategy**: Used grid search to find optimal dense/sparse embedding split (α) balancing semantic matching with keyword matching, improving retrieval quality.

3. Retrieval
    - 

4. Evaluation
    - **Data**: 675 synthetic queries and expected chunks (Generated by Claude Haiku 4.5)
    - **Metrics**:
        - Hit@1: Mean hits in top 1 retrieved chunks
        - Hit@3: Mean hits in top 3 retrieved chunks
        - Hit@5: Mean hits in top 5 retrieved chunks
        - Mean Reciperocal Rate (MRR): Mean rank of first relevant chunk. 
        - Hard Negative Contamination: % of queries where a hard negative outranks the positive


## Project Structure:
